# 37. カレンダー中心ホームと分析画面実装まとめ

## これは何のドキュメント？

[Issue #59](https://github.com/t161121t/sharewallet/issues/59) の「ホームをカレンダー中心にし、分析画面を分離する」を実装した記録です。これまでのホームには、全体・グループ・ジャンルという3つの集計タブがありました。本変更では、毎日の確認をする場所と、月ごとの振り返りをする場所を分けました。

## まず結論（今回できたこと）

- ホームを月間カレンダーに変更した
- 支出がある日には印を付け、日をタップするとその日の明細を表示するようにした
- 新しい「分析」ページで、月合計・先月比・カテゴリ別・6か月推移を見られるようにした
- 下部ナビゲーションに「分析」を追加した

## 背景 — なぜこの変更が必要だったか

ホームは毎日開く画面です。グループ別・カテゴリ別の細かい集計を最初に並べると、「今日何に使ったか」を見つけにくくなります。一方で、月の傾向を知るための集計や推移グラフも重要です。

そこで、ホームでは日付から支出を振り返り、分析ページでは月全体を比較する役割にしました。

## 選択肢の比較

| 選択肢 | 良い点 | 課題 | 採用 |
| --- | --- | --- | --- |
| 既存ホームにカレンダーと分析を追加 | 画面を増やさない | 情報が多くなり、毎日使いにくい | しない |
| ホームをカレンダー、分析を別ページ | 日々の確認と振り返りを分けられる | 下部ナビに1項目増える | 採用 |
| カレンダーを月別の履歴ページに置く | 実装変更が小さい | ホームを開いたときに日々の記録を見られない | しない |

## 目的

| 区分 | 内容 |
| --- | --- |
| 主目的 | 支出を日付単位で確認しやすくする |
| 主目的 | 月ごとの傾向を独立した画面で確認できるようにする |
| あえてやらなかったこと | 支出の編集・削除をカレンダー内に直接置くこと |
| あえてやらなかったこと | 年単位の比較や予算機能を今回の画面に追加すること |

## 何を実装したか

### 月指定できる集計API

`GET /api/dashboard/summary?year=2026&month=9` のように年月を指定できるようにしました。年月が不正なら400を返すため、JavaScriptの日時変換で年が意図せず変わる問題を防げます。

```ts
if (!Number.isInteger(year) || year < 2000 || year > 2100 || month < 1 || month > 12) {
  return NextResponse.json({ error: "year は2000〜2100、month は1〜12で指定してください" }, { status: 400 });
}
```

### カレンダー用API

`GET /api/dashboard/calendar?year=2026&month=9` を追加しました。ログイン中の本人が支払った支出だけを、日付ごとに合計・件数・明細へまとめて返します。グループのメンバーであることも条件にしているため、閲覧権限のない支出は返しません。

```ts
const day = byDate.get(date) ?? {
  date, totalPersonalAmount: 0, expenseCount: 0, expenses: [],
};
day.totalPersonalAmount += expense.amount;
day.expenseCount += 1;
```

### 6か月推移API

`GET /api/dashboard/trend?year=2026&month=9` を追加しました。指定月を含む6か月分について、月に支出がない場合も金額0の点を返します。グラフの月が途中で欠けません。

### ホーム画面

`src/app/dashboard/page.tsx` をカレンダー中心の画面に置き換えました。

1. 月合計と前月・次月ボタンを表示する
2. 支出のある日を小さなゴールドの点で示す
3. 日を選ぶと、その日のカテゴリ・メモ・グループ・金額を表示する
4. 履歴ページへのリンクで全明細を確認できる

### 分析画面

`src/app/analysis/page.tsx` を追加しました。月を切り替えながら、次の情報を確認できます。

- 指定月の個人支出と先月比
- 金額の大きい順のカテゴリ別内訳
- 指定月までの6か月推移

### ナビゲーションと型

`BottomNav` に「分析」を追加しました。APIレスポンスは `DashboardCalendar` と `DashboardTrend` として型定義し、フロントエンドが受け取るデータの形を固定しています。

## よくある質問

### なぜカレンダーには「自分が支払った」支出だけが出るのですか？

既存のホーム集計と同じ基準にそろえるためです。グループ全体の金額と自分が支払った金額を混ぜると、月合計の意味が分かりにくくなるためです。

### 支出がない月でもグラフは表示されますか？

表示されます。金額を0として返すため、6か月分の月名がそろいます。

### カレンダーの日を押しても支出がない場合は？

「この日の支出はありません」と表示します。ほかの日を選ぶか、入力画面から支出を登録できます。
