## 実装済み機能（主要）

### 1) 認証・認可

- `POST /api/auth/register`, `POST /api/auth/login` を実装済み
- `jose` による JWT（`HS256`, 7日）発行/検証
- `src/lib/auth.ts` で `requireAuthUserId`, `assertGroupMember`, `assertGroupRole` を共通化
- ロール: `OWNER` / `ADMIN` / `MEMBER`

### 2) グループ運用

- グループ CRUD: `GET/POST /api/groups`, `GET/PUT/DELETE /api/groups/[groupId]`
- メンバー追加/除外: `POST /api/groups/[groupId]/members`, `DELETE /api/groups/[groupId]/members/[userId]`
- 最後の OWNER が脱退できないガード実装済み

### 3) 支出登録と配分

- 支出 CRUD: `GET/POST /api/groups/[groupId]/expenses`, `PUT/DELETE /api/groups/[groupId]/expenses/[expenseId]`
- `ExpenseShare` による配分比率保存（ユーザーごとの `%`）
- 合計100%検証、不正メンバー検証、支払者の所属検証を API 側で実装

### 4) 割り勘・精算

- 精算計算ロジック: `src/lib/settlement.ts` の `calculateSettlement`（収支差分算出）
- 最小送金回数最適化: `minimumCashFlow` アルゴリズムで送金本数を最小化
- 精算 API: `GET /api/groups/[groupId]/settlement` で精算結果を返却
- 精算画面 UI: `/groups/[groupId]/settlement` で送金指示・残高内訳を表示
- 精算画面への導線: expense/history ページの「精算を確認」ボタン

### 4) ダッシュボードとUI

- ダッシュボード集計 API: `GET /api/dashboard/summary`
- グループ別・カテゴリ別・先月比の表示
- `expense` 画面で円グラフに実データ反映済み
- 共通 UI（BottomNav / PageTransition / Toaster）を導入済み

### 5) インフラ・データ基盤

- Prisma v7 + `@prisma/adapter-pg` + `pg`
- PostgreSQL（Supabase）運用
- `DATABASE_URL`（pooler）と `DIRECT_URL`（migration）を分離

## 補足（今回の更新意図）

- 旧版では「未実装」扱いだった機能の多く（グループ作成、支出編集/削除、メンバー管理など）が現在は実装済みのため、実コード基準に更新
- 今後の開発論点として、要望のあった **割り勘精算** と **レシートOCR** を明示的に分離
- 実装順を「コア価値（精算/OCR）→ 品質（テスト/CI）→ 拡張機能」で見通せるよう再構成
